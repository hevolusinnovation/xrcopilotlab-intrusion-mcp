Il Dev Tunnel, gli URL e la chiave per XRCopilotLab sono sulla pagina del server (localhost:8089). Qui incolli l'indirizzo e la chiave del server da attaccare.

Server da testare

● lab-01 · laboratorio
Per provare un altro server con il pacchetto installato: il suo indirizzo API e la sua chiave. La chiave prova che amministri quel server.
Senza un server da testare gli attacchi partono solo verso lab-01, dentro la rete del laboratorio, da indirizzi di documentazione (RFC 5737) con città inventate. Verso un server esterno partono dal nostro indirizzo e solo gli attacchi web, e solo dopo che la chiave ha provato che puoi già leggere quel server.
